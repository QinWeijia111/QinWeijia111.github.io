## 项目概述

Multica Learning 以开源项目 Multica 为研究对象，关注 Agent Runtime 的实际行为，并把源码证据转化为可阅读、可复核的技术内容。

## 真实问题

复杂 Agent 系统横跨多个层次。仅凭文档或单个函数很难解释实际行为；研究结果也容易在写作与迭代中失去证据链。

## 我构建了什么

- **M01–M06**：围绕 Agent Runtime 完成六个核心模块。
- **Source Verification**：将结论连接到源码证据，区分事实与推断。
- **Agentic Workflow**：组织研究、教程生产、技术评审与交接。
- **Learning Squad**：按明确角色顺序协作，保留人工审核与合并环节。
- **Online site**：把研究内容持续发布为公开学习站。
